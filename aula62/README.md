# Frontend da Aula 62

Copie a pasta `public` deste pacote para dentro da pasta `aula62`, substituindo ou mesclando com a pasta `public` existente.

Depois, inicie o servidor Express e abra `http://localhost:3000` (ou a porta configurada no `.env`). O JavaScript usa as rotas `/usuarios` do mesmo servidor.

Arquivos:

- `public/index.html`: estrutura da página;
- `public/css/style.css`: aparência e responsividade;
- `public/js/usuarios.js`: integração com o CRUD.
