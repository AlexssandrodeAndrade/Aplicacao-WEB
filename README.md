# 🚀 Aplicações WEB - Estudos e Práticas

Este repositório foi criado para armazenar os códigos desenvolvidos durante as aulas de **Aplicações WEB**. O objetivo é servir como um laboratório de estudos para prática de tecnologias de frontend e backend.

## 📚 Conteúdo do Repositório
O projeto está organizado por pastas representando cada aula:
*   **Aulas**: Exercícios práticos de HTML5, CSS3 e JavaScript.
*   **Temas abordados**: Estruturação de páginas, formulários, estilização básica e lógica de programação para web.

## 🛠️ Tecnologias Utilizadas
*   HTML5
*   CSS3
*   JavaScript

## 👨‍💻 Objetivo Pessoal
Utilizo este repositório para manter meu fluxo de aprendizado contínuo, complementando minha experiência de 9 anos como programador, explorando novas formas de estruturar aplicações voltadas para a web.
